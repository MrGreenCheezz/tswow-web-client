# Сравнение кадров оригинального клиента и WebClient

`compare-parity-png.mjs` сравнивает PNG с одинаковым разрешением. Первый кадр оригинала служит основой для `overlay.png` (смешивание 50/50) и `heatmap.png` (красный цвет, яркость усилена в 4 раза). `metrics.json` содержит показатели для всего кадра и заданных областей. Оригинальные кадры и результат держите, например, в `research/`: каталог исключён из Git. Не добавляйте изображения из оригинального клиента в репозиторий.

Пример из корня проекта:

```powershell
node tools/compare-parity-png.mjs `
  --original research/captures/goldshire-original-1.png `
  --original research/captures/goldshire-original-2.png `
  --original research/captures/goldshire-original-3.png `
  --webclient research/captures/goldshire-webclient.png `
  --regions research/captures/goldshire-regions.json `
  --out-dir research/compared/goldshire
```

Файл областей — массив прямоугольников в пикселях. Области могут пересекаться; полный кадр добавляется автоматически:

```json
[
  { "name": "world", "x": 0, "y": 0, "width": 1280, "height": 590 },
  { "name": "action-bar", "x": 350, "y": 590, "width": 580, "height": 130 }
]
```

Метрики каждой области: нормализованная средняя абсолютная ошибка RGB (`meanAbsoluteErrorRgb`, 0–1), нормализованная среднеквадратичная ошибка RGB, доля пикселей с отклонением хотя бы одного канала больше `--threshold` (по умолчанию 16) и максимальное отклонение канала (0–255). Прозрачные PNG сравниваются как изображение на чёрном фоне. `webclientToOriginal` содержит результат против каждого кадра оригинала; `originalRepeatPairs` — все попарные различия кадров оригинала. Поля `webclientMaeRange` и `originalRepeatMaeRange` дают минимум, медиану и максимум этих ошибок. При одном кадре оригинала оценка естественного разброса равна `null`.

Перед съёмкой закрепите разрешение, DPR, UI scale, персонажа, позу, камеру, время суток, погоду и графический профиль. Сделайте повторы оригинала в одном состоянии, затем соответствующий кадр WebClient. Проверка совпадения размеров не выравнивает камеру или анимацию. Наложение помогает найти сдвиг, области — отделить мир от интерфейса. `--threshold` задаёт только диагностическую долю отличающихся пикселей; утилита не выставляет статус «принято». Даже при малой ошибке отсутствующий объект может быть критичен, а различия рендера могут дать большую ошибку без игрового дефекта. Критерии принятия задаются после просмотра кадров и калибровки на повторах оригинала.
