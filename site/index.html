Регистрация

Логин — латиница и цифры, 3–16 символов. Пароль — 6–16 символов без пробелов. Регистр букв в игре не различается.

Приложение

Отдельное окно для Windows: та же игра, без вкладок браузера, на весь экран по F11. Обновляется само.

  1. Скачайте архив и распакуйте его целиком в любую папку.
  2. Запустите WoWWebClient.exe.
  3. Если Windows скажет «Система Windows защитила ваш компьютер» — «Подробнее» → «Выполнить в любом случае».
