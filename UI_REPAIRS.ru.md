# Исправления интерфейса WebClient — 04.09.2026

Результат доступен через локальный Vite на `localhost:5173`. Gateway на `localhost:8090`
перезапущен с поддержкой данных рецептов и камней. После обновления страницы заново войдите персонажем.

## Поведение

- **Почта:** оформление и текстуры обычного клиента, семь писем на странице,
  отдельное окно чтения, вкладка отправки, до 12 вложений и сумма в золоте/серебре/меди.
  Ошибка сервера сохраняет черновик; повторная отправка заблокирована до ответа.
  Ответ доступен после загрузки имени отправителя. Имена и вложения обновляются
  после получения метаданных. Escape закрывает почту и её окно чтения.
- **Панели над существами:** длинное имя сокращается до свободного места перед уровнем;
  процент здоровья, текущее/максимальное здоровье выбранной цели, читаемая полоса применения
  заклинания. Для неизвестного здоровья процент не выдумывается.
- **Портрет слева сверху:** используется стойка персонажа; временное отсутствие исходной
  модели сохраняет последний кадр только для того же GUID. Возврат canvas из FrameXML
  больше не очищает его повторным присваиванием прежнего размера.
- **Сумки:** постоянная сетка из четырёх столбцов; изменение размера отключено,
  квадратные слоты и их иконки согласованы при изменении экрана и масштаба UI.
- **Камни:** подсказки показывают установленные камни, описания, гнёзда, бонус и добавочное
  радужное гнездо. «Вставить камни» доступно через меню предмета и `/socket`.
  Выбор из сумок, подтверждение замены, ожидание штатного серверного результата;
  прежнее извлечение через OP85 сохранено. Дубли GUID, пропавшие предметы,
  несовместимые метакамни и стопки из нескольких камней не отправляются.
- **Книга и профессии:** рецепты и скрытые служебные способности отделены от книги;
  профессии проверяются по фактически изученным навыкам персонажа. Классовые и расовые
  пассивные способности сохраняются. У каждой профессии одинаковое отдельное окно:
  поиск изученных рецептов, сложность, результат, реагенты, доступное количество,
  инструменты, создание, выбор предмета для зачарования и отмена применения.

## Дополнительные исправления: таланты и невидимый камень

Повторное открытие «Универсальных талантов» через N/кнопку обходило обычную
группировку Lua-изменений. Каждое изменение виджета запускало полную синхронизацию
DOM: первое открытие публиковало 897 промежуточных состояний. Путь теперь использует
`runInMutationBatch` и публикует окно один раз. На настоящем renderer с активными
аддонами: первое открытие 7310,5 → 110,7 мс, повторное 4021,6 → 57,9 мс.
Проверены N, кнопка, Escape, повторное открытие и сохранение DOM.

`GameTooltip:AddLine(..., true)` теперь сохраняет запрос переноса и цвет строки.
Строки определяют естественную высоту фона, ширина ограничена, положение учитывает
фактический размер, масштаб и край экрана. Проверены 1000/380 px и оба края экрана.
Файлы: `src/browser/framexml/FrameXmlWorldMount.ts`,
`src/browser/glue/GlueWidgets.ts`,
`src/browser/ui/framexml_compat/FrameXmlDomRenderer.ts`.

Окно инкрустации различает ожидание item-query и действительно отсутствующие данные.
Неизвестные камни больше не исчезают из списка. Индекс свойств можно обновить;
выбирается первое существующее гнездо. Для стопки добавлено явное отделение одного
камня стандартным `CMSG_SPLIT_ITEM`: UI ждёт новый GUID и уменьшение исходной стопки,
затем требует отдельного подтверждения вставки. Автоматического расхода камней нет.
Файлы: `src/browser/ui/Socketing.ts`, `ItemTooltip.ts`,
`src/browser/ItemEnchantments.ts`.

**Причина конкретного отсутствовавшего одиночного камня:** предмет 65827
«Попятиться Gem» ссылается на GemProperties 7635. В `ids.txt` это старый
`gem-abilities:gem-1754`, связанный с enchantment 9635. Все три записи отсутствуют
в текущем наборе генерируемых камней; свойств 7635 и соответствующего зачарования
нет и в активных DBC. Каталог проверен непосредственно и через gateway; совпадает
с `DataDir` запущенного worldserver. Другие камни с похожим названием используют
другие spell ID, поэтому автоматическая замена была бы изменением игрового предмета.
UI теперь показывает причину недоступности. Восстановление/миграция этого старого
предмета в модуле TSWoW остаётся отдельной задачей; фиктивные свойства не создавались,
инвентарь и серверные таблицы не изменялись.

Дополнительно синхронизированы DOM fixtures, версия кэша заклинаний и проверки
владения окнами с текущим UI. Проверка геометрии реплики выявила пересечение с меткой
рейда: зазор над максимальной панелью увеличен до 84 px.

Для общего коммита исключены локальный профиль Chrome и сгенерированный кэш карт.
CI запускается также для `master`. Старая локальная `master` сохранена как
`archive/master-before-webclient-fixes`; новая `master` основана на текущей публичной
истории `main`, без возврата к старой истории проекта.
