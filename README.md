# TSWoW WebClient

Клиент WoW 3.3.5a (build 12340) для TSWoW/TrinityCore. Игра одна, способов запустить её несколько:

- **веб-версия** — страница в браузере;
- **Electron-версия** — та же страница в отдельном окне, чьи процессы закреплены за
  производительными ядрами и не притормаживаются в фоне;
- **для других игроков** — ваш компьютер раздаёт игру по сети, а игроки открывают ссылку или
  запускают присланное приложение.

Код игры у всех вариантов общий (`src/`).

## Что запускать

Все bat-файлы лежат в одной папке [`bat/`](bat/); номер в имени — группа: `0x` играть, `1x` шлюз,
`2x` сборка, `3x` другие игроки. Подробно, с параметрами, — в [`bat/README.md`](bat/README.md).

| Задача | Что нажать | Что получится |
| --- | --- | --- |
| Разработка в браузере | `01 Играть - браузер.bat` | поднимет шлюз и Vite, откроет http://127.0.0.1:5173/ |
| Разработка в Electron | `02 Играть - приложение (разработка).bat` | поднимет шлюз и Vite, откроет окно Electron |
| Играть на этой машине | `21 Сборка - приложение.bat`, затем `03 Играть - приложение (собранное).bat` | `dist\electron\WoWWebClient.exe`, шлюз запускает сам |
| Проверить собранную веб-версию | `20 Сборка - игра.bat`, затем `23 Страница - собранная.bat` | `dist\web` на http://127.0.0.1:5173/ |
| Набор для игроков | `30 Игроки - собрать набор.bat` | `dist\Для игроков\` и `dist\Для игроков.zip` — его и отправлять |
| Проверить связку для игроков у себя | `31 Игроки - проверить у себя.bat` | тот же сервер только на `127.0.0.1` и то же приложение против него |
| Пустить других игроков | `32 Игроки - начать раздачу.bat` | ссылка `http://<PUBLIC_HOST>:8091/` |

Лаунчеры разработки запускают только то, чего не хватает, каждое в своём окне. Уже работающие
шлюз и Vite используются как есть.

## Папки

| Папка | Что там |

| [`bat/`](bat/) | все лаунчеры: играть, шлюз, сборка, другие игроки; [руководство](bat/README.md), в том числе по раздаче |

## Шлюз

Без шлюза страница остаётся чёрной: экран входа берёт файлы клиента через него. Шлюз соединяет
страницу с authserver/worldserver и отдаёт ресурсы из клиента и dataset.

- `10 Шлюз - запустить.bat` — собрать и запустить шлюз. Лаунчеры разработки делают это сами.
- `11 Шлюз - перезапустить.bat` — перезапустить шлюз после сборки TSWoW. Пересоберёт, если менялся `src/`.
- `12 Шлюз - остановить.bat` — остановить шлюз, в том числе раздачу для игроков.
- `node tools\build-gateway.mjs` — собрать только шлюз (`src/gateway` и то, что он импортирует;
  `tsconfig.gateway.json`) в `dist\code` за несколько секунд, без страницы и `vite build`: ошибка
  типов в коде страницы шлюзу не мешает. `--check` ничего не собирает и отвечает, старше ли сборка
  исходников шлюза (код 0 — старше). Страница, Electron-версия и тесты собираются `npm run build`.
- Собранный `WoWWebClient.exe` запускает шлюз сам и останавливает его при закрытии окна.
- `32 Игроки - начать раздачу.bat` запускает шлюз, открытый для других игроков. Через него же
  работает и разработка на этой машине.

## Как это устроено

```text
Браузер или окно Electron
   │  страница: Vite :5173 (разработка), dist/web :5173 (собранная), dist/web :8091 (для игроков)
   │  WebSocket /auth и /world, HTTP-ресурсы
   ▼
Шлюз :8090 (src/gateway → dist/code) ──> authserver :3724, worldserver :8085
   └─> DBC/карты TSWoW, MPQ клиента, локальные кеши data/
```

Страницу на `127.0.0.1:5173` одновременно раздаёт что-то одно: Vite, собранная веб-версия или
собранная Electron-версия. Шлюз принимает страницу только с адресов из `ALLOWED_ORIGINS`;
раздача для игроков (`32`) добавляет туда адрес для игроков сама.

## Где что лежит

| Путь | Что там |
| --- | --- |
| `src/browser/` | страница: рендер мира, интерфейс, ввод |
| `src/gateway/`, `src/auth/`, `src/transport/`, `src/protocol/`, `src/world/` | шлюз, авторизация, протокол, состояние мира |
| `src/generated/` | сгенерированные таблицы (протокол, DBC, строки) |
| `index.html`, `glue.html`, `framexml.html`, `character-lab.html` | страницы — точки входа Vite (`vite.config.mjs`) |
| `tools/` | генераторы, извлечение ресурсов, запуск шлюза (`start-gateway.mjs`), раздачи (`start-server.mjs`) и набора для игроков (`player-kit.mjs`), проверки |
| `tests/` | Node-тесты |
| `bench/` | бенчмарк производительности |
| `docs/` | [план работ](docs/WORK_PLAN.ru.md), [проверки в игре](docs/LIVE_CHECKS.ru.md), [памятка тестерам](docs/PLAYTEST.ru.md), методика, замеры производительности, раздача другим игрокам; `archive/` — история |
| `public/`, `data/` | статика страницы и локальные кеши ресурсов из клиента (не в git) |
| `dist/` | сборки: `web/`, `code/` (шлюз), `electron/`, `player/`, `Для игроков/` (не в git) |

## Первый запуск

1. Node.js 22+ — системный или встроенный `.runtime\node` (bat-файлы находят его сами).
2. `npm install` в корне; для Electron-версии и приложения игроков — ещё `npm install` в `electron/`.
3. Скопировать `.env.example` в `.env` и указать пути к клиенту, TSWoW и TrinityCore;
   `npm run doctor` проверит настройки. Для раздачи другим игрокам — ещё `PUBLIC_HOST`.
4. Один раз `22 Сборка - ресурсы.bat` — извлечь иконки и метаданные из клиента.

`dist\web` и `dist\electron` содержат данные из вашего клиента — это локальные сборки. Как файлы
игрокам отправляется только набор из `dist\Для игроков` (приложение `WoWWebClient.zip` и две
памятки): в нём нет ничего из клиента WoW. Но раздача (`32`) отдаёт `dist\web` по сети (порт 8091),
а шлюз — ресурсы клиента: их получает каждый, кто откроет ссылку. Внутри `dist\web` лежит
предупреждение `LOCAL_ONLY-NOT-FOR-REDISTRIBUTION.txt`; кому открывать доступ — решение владельца
([план раздачи](docs/DISTRIBUTION_PLAN.ru.md), «Решения за владельцем»).

## Команды npm

| Команда | То же, что |
| --- | --- |
| `npm run dev` | Vite из `01` (без запуска шлюза) |
| `npm run build` | `20 Сборка - игра.bat` |
| `npm run preview` | `23 Страница - собранная.bat` |
| `npm run electron` | окно из `02` (без запуска шлюза и Vite) |
| `npm run electron:build` | `21 Сборка - приложение.bat` |
| `npm run gateway` | `10 Шлюз - запустить.bat` |
| `npm run server` | `32` (без остановки локального шлюза и пересборки) |
| `npm run player:build` | приложение из `30` (без набора: `node tools\player-kit.mjs`) |
| `npm run test:source` | все Node-тесты по текущим исходникам |
| `npm run bench` | бенчмарк, см. `bench/README.md` |
