# Electron-версия

Та же страница, что и в веб-версии, в отдельном окне Electron. Отличия от браузера:

- процессы окна закреплены за производительными ядрами: на i7-12700KF с Windows 10 браузер иначе
  может оказаться на энергоэффективных, а кадр там в ~1,7 раза дороже;
- повышенный приоритет процессов, окно не притормаживается в фоне;
- вместо чёрного экрана окно говорит, чего не хватает (шлюза, Vite, связи с сервером), и само
  открывает игру, когда это появится;
- F11 — полный экран, F12 — DevTools, Ctrl+R — перезагрузка.

Код игры здесь не дублируется: страница берётся из общего `../src/browser/`. Из этой же папки
собирается приложение для других игроков (см. [`../online/`](../online/)).

## Файлы

| Файл | Что это |
| --- | --- |
| `main.cjs` | главный процесс: окно, выбор страницы, закрепление за ядрами, приоритет, экраны ожидания |
| `static-server.cjs` | раздаёт собранную страницу: в собранной версии вместо Vite; им же пользуется `tools\start-server.mjs` |
| `gateway.cjs` | запускает шлюз, если собранная версия не нашла уже работающий; проверка портов |
| `cpu-policy.ps1` | вычисляет маску производительных ядер и применяет её к процессам окна |
| `build.mjs` | упаковка: `..\dist\electron\` (для этой машины) или `--player` → `..\dist\player\` (для игроков) |
| `start-dev.bat` | разработка в один клик: поднимает Vite и шлюз, если их нет, и открывает окно |
| `build.bat` | полная сборка: веб-версия (`npm run build`), затем упаковка (`build.mjs`) |
| `start-built.bat` | запуск собранной версии `..\dist\electron\WoWWebClient.exe` |

Перед первым запуском: `npm install` в этой папке (ставит Electron).

## Разработка

`start-dev.bat` запускает недостающее в отдельных окнах: Vite через `web\start-dev.bat
--no-browser` и шлюз через `start-gateway.bat`. Затем открывает окно Electron. Пока шлюз
собирается, окно показывает «Шлюз не запущен» и открывает игру, как только тот заработает.

## Сборка и запуск собранной версии

1. `build.bat` → `..\dist\electron\WoWWebClient.exe` (Electron + эта оболочка + собранная страница).
2. Vite **не** должен быть запущен: собранная версия сама раздаёт страницу на
   http://127.0.0.1:5173/ — единственном адресе, который шлюз принимает по умолчанию.
3. `start-built.bat` или сам `WoWWebClient.exe`.

Шлюз отдельно запускать не нужно. Если на 127.0.0.1:8090 никто не отвечает, exe сам запускает его
из этой папки WebClient (`node tools/start-gateway.mjs` — на коде, собранном тем же `build.bat`)
и останавливает при закрытии окна. Пока шлюз стартует, в окне надпись «Запуск шлюза…». Если он
упал, в окне будет его ошибка, а журнал лежит в `.runtime\logs\electron-gateway.log`. Уже
запущенный шлюз (`start-gateway.bat`, `restart-gateway.bat`, `online\start-server.bat`) exe
использует как есть и не останавливает.

Собранная версия ищет папку WebClient на два уровня выше себя. Если перенести `dist\electron\` в
другое место, шлюз придётся запускать вручную: окно подождёт его. Распространять эту папку
нельзя — в ней страница, собранная из данных вашего клиента. Игрокам отправляется приложение из
`online\build-player.bat`.

## Какую страницу открывает окно

Первое подходящее:

1. `--webclient-url=<адрес>` — открывается как есть, без проверок (так работает бенчмарк).
2. `--server-url=<адрес>` или `server.json` рядом с `main.cjs` — это приложение игрока
   (`build.mjs --player`). Открывается страница с сервера; пока сервер или его шлюз не отвечают,
   окно показывает «Нет связи с сервером».
3. Собранная страница: `--web-dir` или вложенная в `dist\electron`. Шлюз запускается сам.
4. Vite dev-сервер на http://127.0.0.1:5173/. Шлюз запускает разработчик, окно его ждёт.

Если страница открыта по обычному http не с `127.0.0.1` (сервер для игроков), оболочка помечает
этот адрес как безопасный. Иначе Chromium не даёт Web Crypto и cross-origin isolation.

Разработка и собранная версия делят один профиль, поэтому настройки интерфейса общие. У приложения
игрока профиль свой.

## Параметры запуска

Передаются через `start-dev.bat`, `start-built.bat` или `WoWWebClient.exe`:

| Параметр | Значение |
| --- | --- |
| `--webclient-url=<url>` | открыть этот адрес, например `http://127.0.0.1:5173/?framexml=1` |
| `--server-url=<url>` | сервер для игроков вместо адреса из `server.json`: так `online\test-local.bat` направляет приложение на `127.0.0.1` |
| `--web-dir=<папка>` | раздавать собранную страницу из папки, например `dist\web` (путь от папки WebClient при запуске через `start-dev.bat`) |
| `--port=<порт>` | порт собранной страницы, по умолчанию 5173; другой порт добавьте в `ALLOWED_ORIGINS` |
| `--cpu-class=fastest\|slowest\|none` | ядра: производительные (по умолчанию; у приложения игрока — `none`), энергоэффективные, на выбор Windows |
| `--priority=normal\|abovenormal\|high` | приоритет процессов, по умолчанию `abovenormal` (у приложения игрока — `normal`) |
| `--window=<ширина>x<высота>` | размер окна, по умолчанию `1600x900` |
| `--uncapped` | без vsync и ограничения частоты кадров (для замеров) |
| `--no-isolation` | без заголовков cross-origin isolation: позы толпы останутся в основном потоке |
| `--no-js-profiling` | без заголовка `Document-Policy: js-profiling`: запись фризов (`O` → «Записать фризы») пойдёт без выборок стеков |
