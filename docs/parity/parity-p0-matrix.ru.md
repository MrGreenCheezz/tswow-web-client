# P0: матрица проверки игровых сценариев

Состояние: 23 сентября 2026 года. Эта матрица уточняет P0 из [`CLIENT_PARITY_PLAN.ru.md`](../CLIENT_PARITY_PLAN.ru.md). Проверены названия и содержание существующих тестов; позднее выполнены первый вход и повторный вход в живой realm через браузерный клиент. Оригинальный клиент в парном проходе не запускался, а игровые P0 ещё не приняты целиком. Текущие unit/source tests используют локальные фикстуры пакетов и состояния; слово `live` в имени теста FrameXML означает подключение `LiveWorldSeam` к фикстуре `WorldClient`, а не сетевое подключение к серверу (пример: `tests/framexml-live-character-regression.test.mjs`).

В `package.json` нет команды браузерного сквозного игрового теста. В `tests/*.test.mjs` нет запуска Puppeteer/Playwright. `bench/run.mjs` запускает браузерные сцены движения и толпы для рендера/FPS, но не проводит игрока через авторизацию, серверные действия и выход. Для P0-01 и части P0-08 есть ручной браузерный проход на локальном realm; все строки ниже всё ещё имеют **непринятый живой результат**. Существующий source test не закрывает строку.

## Общий критерий для каждой строки

На выделенном тестовом realm или согласованном снимке состояния записать ревизии WebClient/TrinityCore, fingerprint dataset и клиентских ресурсов, персонажа и его начальное состояние, настройки графики и UI, браузер/GPU/разрешение. Выполнить одинаковые действия в оригинальном WoW 3.3.5a build 12340 и WebClient. Сохранить последовательность действий, сетевую трассу с обязательными полями, серверное состояние до/после и кадры/видео интерфейса. В принятом проходе `webclientUnhandledOpcodes()` пуст, нет ошибок `onPacketError` и консоли, итог действия подтверждён сервером, а вид и управление сопоставлены с оригиналом. Для действий, видимых другим игрокам, повторить наблюдение вторым персонажем. Секреты сессии и содержимое `.env` не записывать.

## Следующий проверяемый шаг

Для каждой строки завести воспроизводимый живой маршрут с конкретным тестовым персонажем и стартовым состоянием, затем автоматизировать хотя бы P0-01 → P0-02 → P0-08 в браузере. Пока нет тестового realm, исходных данных для парного прохода оригинала и записи серверного результата, ставить этим строкам статус «пройдено» нельзя.
