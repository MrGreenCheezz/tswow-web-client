## 3. Расхождения со спецификацией, решённые по Wow.exe

- Ремонт отправляется и для неизношенного предмета. ПКМ в режиме ремонта чинит до продажи. Показанная цена бывает на 1 медяк больше списанной: клиент округляет к ближайшему чётному, ядро отбрасывает дробь.
- `SetPVP(true)` и `SetPVP(nil)` выключают PvP. `SetDungeonDifficulty` принимает только 1–2. Если персонаж вошёл в мир с уже идущим таймером, `GetPVPTimer` отдаёт 999.
- `GetZonePVPInfo`: флаги берутся у подзоны, без обхода всей цепочки; исключения для инстансов нет; вне PvP-realm'а территория есть только у зон с флагом 0x10.
- `ZONE_CHANGED_NEW_AREA` приходит только при смене id зоны, без парного `ZONE_CHANGED`.
