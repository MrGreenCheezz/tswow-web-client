### 4.5 Native DOM UI

Со штатным HUD большинство native-окон скрыто. Сток зависит от native-частей: ввод (Controls → Actions → useSlot), физика, камера, пикинг, курсор, таблички, пузыри чата, числа урона, прицел наземных заклинаний, экран загрузки; таблицы клавиш и настроек служат ему хранилищем.

- **Отсутствует:** достижения, управление рейдом.
- **Мелочи:**
  - предложение LFG спрашивается дважды;
  - сырые ID подземелий и полей боя в подсказках;

### 4.12 Безопасность (актуально при публичной раздаче `online/start-server.bat`)

| Риск | Уровень | Суть | Отметка |
|---|---|---|---|
| Падение gateway от одного TCP-запроса | высокий при раздаче, низкий локально | В `server.on("upgrade")` (`Gateway.ts:3436-3455`) `new URL(request.url…)` стоит вне try, у сокетов на ветках 403/404/503 нет обработчика `error`, глобального `uncaughtException` нет. Upgrade с чужим Origin + RST или `GET //[::1` роняют процесс; супервизор завершается, с ним и страница | [✔] код; воспроизведено на модели обработчика, не на живом gateway |
| Все игроки для TrinityCore — 127.0.0.1 | средний | Бан по IP банит всех; привязка учётки к IP не работает; перебор паролей не ограничен (`WrongPass.MaxCount = 0`), а при включённой защите с `BanType = 0` забанит loopback | [код] |
| Страница по http без TLS | средний | Посредник может подменить JS и снять пароль; приложение игрока помечает http-origin безопасным и скрывает проблему | [код] |
| Патчи по HTTP | средний (вне WebClient) | `patches:check`: 1277 URL манифеста по HTTP, «executable Lua/DLL patch delivery is not authenticated» | [✔] |

| `ALLOWED_ORIGINS=*` вместе с `MODULE_UI_WRITE=1` | низкий | Любой сайт в браузере владельца сможет `PUT /modules/*` | [код] |
