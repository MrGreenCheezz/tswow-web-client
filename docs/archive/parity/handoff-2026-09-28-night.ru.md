Источник живых фактов — журнал worldserver (`tswow-install/modules/default/realms/realm/Server.log`, network DEBUG), см. заметку памяти `worldserver-log-diagnosis`.

Причина: штатный `UIParent` OnUpdate вызывает `RequestBattlefieldPositions(elapsed)` каждый кадр, а наша привязка отправляла пакет на каждый вызов.

- Загрузка: каждый промах кеша gateway — отдельный процесс node, заново открывающий 30 источников архивов (~0,4 с), по одному на семейство, без приоритета. Плюс 60-ярдовый поводок комнат прятал дальние залы с жаровнями (в проёмах было видно небо Элвинна), а юниты освещались уличным светом Light 1.
