## 2. Особые условия — когда будет возможность

Нужны второй клиент (лучше оригинальный Wow.exe), установка с модулями, собранное приложение, тестовая раздача, учётная запись с 2FA или ваше решение.

- [ ] **Одноразовый код (2FA)** (10.10). Учётная запись с двухфакторной защитой: после пароля появляется поле шестизначного кода, верный код пускает, неверный — отказ.
- [ ] **Отбрасывание глазами второго клиента** (5.01). Под Громом и молнией шамана или ударом босса персонаж летит дугой, клавиши не рулят; второй клиент видит ту же дугу вверх.
- [ ] **Доп. панели команд хранятся на сервере** (3.32). Включите дополнительную панель, зайдите тем же персонажем в другом браузере и в Wow.exe — панель видна.
- [ ] **Пловец глазами второго игрока** (5.06). Второй клиент видит пловца так же — по плечи в воде.
- [ ] **Модуль, заменяющий окно талантов** (3.26). С таким модулем (например, retail-talents): N открывает окно модуля и закрывает его, Escape тоже закрывает; клавиша символов открывает стоковое окно талантов на вкладке символов, без «Ошибка загрузки»; сброс талантов у тренера открывает стоковое окно талантов с вопросом (3.45). Нужна установка с модулем.
- [ ] **Сообщения модулей при входе** (9.03). С аддонами модулей: окна сразу получают свои данные, после перезагрузки интерфейса ничего не приходит дважды. Нужна установка с модулями (сейчас только default).
- [ ] **Обновление приложения игрока** (10.17). Соберите `online\build-player.bat`, скопируйте `dist\player\WoWWebClient` в другую папку, соберите ещё раз; запустите `online\test-local.bat browser`, затем скопированный exe с `--server-url=http://127.0.0.1:8091/`: в углу «Доступна новая версия», «Обновить» скачивает, приложение закрывается и открывается уже новой версией. Сохраните копию папки `.runtime\player-update-key` — без неё игрокам придётся один раз переставить приложение вручную.
- [ ] **Electron: падение отрисовки** (1.29). В собранном приложении завершите в диспетчере задач процесс отрисовки: игра сама перезагружается, после трёх падений за минуту — сообщение об ошибке.
- [ ] **Сборки мусора в приложении** (12.16). Запустите упакованное приложение так и пришлите `gc-live.json` и запись `webclientRecordFreezes()` из города:

  ```
  WoWWebClient.exe --trace-startup=v8,disabled-by-default-v8.gc --trace-startup-format=json --trace-startup-duration=120 --trace-startup-file=gc-live.json
  ```

- [ ] **Полная запись производительности** (12.01, 12.07). Около часа: несколько сцен по три прохода с `webclientRecordFreezes()` — вход в мир, лес, город, подземелье, бой. Нужна для итогового замера FPS (14.26); подробные шаги пришлю, когда будете готовы.
- [ ] **Раздача: кеш и закрытые страницы** (10.13). На тестовой раздаче (адрес WSL) откройте игру дважды: второй раз не скачивается заново, служебные страницы снаружи не открываются.
- [ ] **Перезапуск раздачи после сборки** (10.15). На тестовой раздаче войдите в игру и соберите данные или аддон в TSWoW: вверху отсчёт «Сервер перезапустится через M:SS», через 5 минут — «Сервер перезапускается после обновления» и выход на экран входа; когда шлюз поднимется — «обновите страницу». Без игроков шлюз перезапускается сразу.
- [ ] **Окно «Сервер недоступен»** (10.16). Откройте игру при выключенном шлюзе: окно с кнопкой «Повторить»; после запуска шлюза страница загружается сама.
- [ ] **Причина без ускорения поз по http** (10.18). На тестовой раздаче откройте игру в браузере по http: в панели производительности строка «в основном потоке — страница не изолирована»; в приложении игрока — «в воркере».
- [ ] **Проверка настроек** (10.19). `npm run doctor` сообщает, отвечают ли серверы входа, мира и шлюз, и не находит ошибок в настройках.
- [ ] **Кадры оригинала для сравнения** (14.25). Одинаковые кадры «Wow.exe / WebClient»: дверь таверны Голдшира изнутри; склон на закате на классическом пресете; ночное небо с луной; облака днём; оранжевая слизь в Нордсколе; миникарта в Тюрьме Штормграда; влажный камень; «Расправа» на бегу; восход луны; пустой щелчок по ячейке боеприпасов.
