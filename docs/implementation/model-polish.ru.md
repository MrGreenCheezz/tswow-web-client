# Улучшение моделей заранее (7.62, 04.11)

Просьба владельца: пройтись по моделям инструментами и сделать их лучше. Проба затенения, сглаживания и рельефа, расчёт веса апскейла текстур существ и предметов, затем решение владельца. Включена настройка «Сглаженные модели» в улучшенной графике (раздел «Тени и рельеф», в точном профиле выключена): копии предметов обстановки и существ с затенением, более круглыми контурами и рельефом на камне, `data/visual-models/` под своими именами, около 1 ГБ.

**Апскейл текстур существ и предметов убран по решению владельца 04.11:** собрали, включили, в кадре разницы почти нет (см. ниже). Настройки и кода больше нет, 6 709 текстур и 2 ГБ удалены. Сжатие HD-текстур при отдаче осталось: оно работает на наборе мира.

Изменение настройки действует с перезагрузки страницы. Игрокам модели идут по `PUBLIC_REFINED_MODELS=1` (сейчас не задано). Новая страница для игроков собирается скриптом `bat\20`.

## Как устроено

- `tools/model-polish.mjs` — три прохода: затенение, сглаживание, рельеф. `tools/model-refine.mjs` — один рецепт копии. `tools/polish-models.mjs --all` — собрать всё заранее; `--out <папка> --steps smooth,relief,ao` — проба отдельных проходов для `bench/lookdev.mjs --model-variants <папка>`.
- **Какие байты писать, задача решает по имени файла**, как и для пространств имён моделей: `refinedModelHash` в `tools/visual-model-key.mjs`, он же `refinedModelFileHash` на шлюзе (`src/gateway/RefinedModelRoute.ts`; тест держит их равными). Анимации остаются на обычном имени: те же клипы, отдельного файла у копии нет.
- **Клиент спрашивает копию (`refined=1`), только если шлюз объявил `refinedModelGeneration`** в `/client/patch-status`. Поэтому шлюз без поддержки никогда не положит обычную модель под URL копии. Модель, которую бейк не осилил, публикуется обычной под тем же именем.
- **Затенение** хранится в длине нормали (`WVM9_NORMALS_CARRY_AO`, `src/browser/ModelVertexAo.ts`): нового потока данных нет, размер файла тот же.
- **Сглаживание** — PN-треугольники (Vlachos 2001) по авторским нормалям. Старые вершины не двигаются, новые получают смесь весов костей и UV. Модели больше 8 000 треугольников (HD-существа из патчей) не сглаживаются, но затенение получают.
- **Рельеф** — только камень, по имени пути (`isStoneModelPath`): на бочке обруч волнится даже при силе 0,4.

Правила против поломок (на каждое есть тест, каждый проверен поломкой правила):

| Что ломалось на снимках | Правило |
| --- | --- |
| Квадратные столбы раздувались, как гроб | нормаль дальше 42° от своей грани, складка больше 65°, поворот нормалей больше 55° |
| Полотно картины уходило за стену | ребро не прогибается внутрь; наклонённая нормаль на плоской поверхности не считается кривизной |
| Трещины на швах UV | новая точка считается один раз на сваренное ребро |
| Авторская острая кромка | вершины с разными нормалями на ребре его запрещают |
| Листва и прозрачное | делится только сплошное и освещённое |

### Текстуры существ и предметов (убраны 04.11)

Замеры ниже сняты до удаления и объясняют его. В наборе `world` снова 12 670 текстур.

| | Текстур | BC7 |
| --- | --- | --- |
| Существа | 1 553 | 0,25 ГБ |
| Предметы на модели | 5 156 | 0,67 ГБ |

PNG-вход ещё 1,05 ГБ, игрокам не отдаётся. Сборка 45 минут: видеокарта 21 минуту, остальное подготовка и сжатие.

- **Видеопамять не растёт.** BC7 ×2: четыре пикселя по байту, столько же, сколько один исходный пиксель RGBA. Счётчик это подтверждает.
- **Растёт загрузка.** На стенде 1,9 МБ вместо 0,5 МБ на 11 текстур, примерно в 3,8 раза до сжатия и только для того, что игрок увидел. С 04.11 HD-текстуры идут через gzip шлюза: шкура кролика 276 КБ вместо 350 КБ при исходном PNG 85 КБ. На всём наборе мира gzip даёт 69 %, brotli 67 % (150 образцов). По http браузер предлагает только gzip.
- **На экране этого почти не видно.** Только текстуры, модели одинаковые: мелкие существа 0,0 % изменившихся пикселей с обычной дистанции и 0,1 % вблизи, крупные существа 0,0 % (но их шкуры в кадр почти не попали: три из них в наборе не оказалось). Сравнение самих файлов выглядит убедительно, но в кадре ×2 заметен, только если пиксель текстуры больше пикселя экрана, а этого почти не бывает. Оружие на персонаже в кадре не мерили. Первый вывод «на оружии заметно сильно» был сделан по файлам и оказался необоснованным.
- **Мало кого касается.** В таблицах этого клиента только 501 из 7 867 обликов существ (6 %) рисует шкуру до 256 px: кролики, лягушки, кошки, курицы, греллы. Остальные 512–1024 из HD-патчей. В Голдшире в радиусе 200 ярдов 30 из 395 существ.
- **В набор вошло только то, что рисуется:** имена из `CreatureDisplayInfo`, `ItemDisplayInfo` и самих моделей. Из 9 552 собранных 2 843 ни на что не ссылались и отброшены.
- **Не стоит того:** BC1 вместо BC7. Непрозрачных лишь 26 % пикселей, выигрыш около 13 %.
- **Не мерили:** подгрузку HD только рядом с игроком.
