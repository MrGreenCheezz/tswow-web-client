2. **«10–28 перепараметризаций» — уже состояние после шага 21** (город 10, движение 28; PERF_STATUS шаг 21, п. 10). Сортировка по виду их не убирает: порядок `scene.add` (≈4222: окружение → скелетная сценерия → корзины → корзины локального света → … → юниты, затем рельеф) даёт пять границ вида на каскад. #### P2-03b — Общие вершинные буферы между внешностями и кастами одной модели · M · P2 · UNT-8

- **Актуально ли.** Открыто. `ModelBuild.ts` `buildModel` (≈767–777) на каждую сборку создаёт шесть новых `BufferAttribute` (`position`, `normal`, `uv`, `uv1`, `skinIndex`, `skinWeight`) над теми же типизированными массивами модели, а `WebGLAttributes` держит GL-буфер по идентичности атрибута (`WeakMap`), так что каждая внешность и каждый каст заново загружают вершины. Хранилища нет (Grep `SharedModelBuffers` — 0). Защита при освобождении для общих идентичностей есть (`disposeEvictedBuiltModels`), учёт — тоже (`BuiltModelCache.#resources`, `ResourceAccountingLedger`).
- **Подход.** `WeakMap<WvmModel, атрибуты>`: атрибуты модели создаются один раз и делятся всеми сборками; у сборки свои только индекс и `wvmSlot`. ##### P2-03b-2 — Заклинания (кастовые сборки) · S–M · GO/NO-GO, сейчас не делать

- **Что.** `#updateVisuals` строит `buildModel(model.wvm, …)` на каждый визуал, `#disposeRenderedVisual` вызывает `built.geometry.dispose()`. Общий выигрыш между *последовательными* кастами возможен только если общий набор переживает освобождение визуала: последняя обёртка не освобождается, а паркуется в малом LRU (`SharedModelBuffers.park(geometry)`, потолок ≈8 МиБ), вытеснение — `dispose()` припаркованной. Без парковки выигрыш только у одновременных кастов одной модели.
- **Почему не сейчас.** В стенде нет сцены массовых эффектов (каталог §6: «сценарий массовых эффектов»), эффект на `render.visuals` невозможно измерить; освобождение заклинаний — единственное «сырое» место, его маршрутизация меняет жизненный цикл визуалов. Делать после UNT-2/UNT-4 и появления сценария; порог — `bufferData` за бой ≥ −40 %, `#visuals`-память не растёт, нет утечек GL-буферов (`renderer.info.memory.geometries` в норме).
