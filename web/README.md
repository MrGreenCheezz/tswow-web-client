# Веб-версия

Клиент как страница в обычном браузере. Код страницы — `../src/browser/`, код шлюза —
`../src/gateway/`; здесь только запуск и сборка.

| Файл | Что делает |
| --- | --- |
| `start-dev.bat` | разработка в один клик: запускает шлюз в своём окне, если он не работает, затем Vite dev-сервер с горячей перезагрузкой и открывает http://127.0.0.1:5173/, когда оба ответят |
| `build.bat` | сборка (`npm run build`): `dist\web\` — страница, `dist\code\` — шлюз |
| `start-built.bat` | раздаёт собранную `dist\web\` на том же адресе, без пересборки (`npm run preview`); шлюз запустите сами |

`start-dev.bat --no-browser` не открывает браузер. Если Vite уже запущен, второй не стартует:
батник только откроет страницу.

`start-dev.bat` и `start-built.bat` занимают один порт 5173 — запускайте что-то одно.

Как пустить в веб-версию других игроков по ссылке — см. [`../online/`](../online/).
